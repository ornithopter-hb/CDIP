# 일정 안내

1. 오늘 날짜(연도 2026)를 확인한다. 셸이 있으면 `date +%F`를 쓴다.
2. `.claude/rules/course.md`의 "수업 일정" 표와 "제출 규칙"을 기준으로 아래를 계산한다. 요일은 날짜로 직접 계산한다(표의 열 이름을 믿지 않는다).
3. 다음 형식으로 짧게 답한다.

```
오늘: YYYY-MM-DD (요일) · N주차
이번 수업: <날짜> <내용>
- Daily Report: <수업 당일> 24:00 마감
다음 수업: <날짜> <내용>
Progress Report
- 진행 중/다음: PR<n> — <step 종료 수업날> + 7일 = <YYYY-MM-DD> 24:00 마감
최근 회의: <docs/01_회의록/ 최신 파일의 날짜와 "정리 및 후속 검토" 요약 한두 줄>
```

- 오늘이 수업이 없는 날이면 "이번 수업" 대신 직전·다음 수업을 보여준다.
- 중간고사·공휴일·최종발표주간은 그대로 표시한다.
- 일정표에 없는 내용(교수님 추가 공지 등)은 추측하지 말고 "일정표 기준"이라고 밝힌다.
