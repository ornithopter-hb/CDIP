# 후보 주제 목록 (3반 1조)

> 기준일: 2026-09-23 회의 · 상태: **주제 미확정**
> 교수님 안내(9/16 수업): 아이디어가 있는 팀은 주제의 **타이틀과 간략 요약**을 미리 전달 가능

## 공통 선정 기준
- 손으로 구동해 움직임이 보이는 기계적 구조 / 시연 가능
- 지양: 스위치 작동만으로 끝나는 구성, 지나치게 익숙한 주제, 제작·시연이 불편한 구성
- 물을 사용하는 시연은 가급적 피함

## 후보별 요약 및 좁혀야 할 개발 문제
| # | 후보 주제 (제안) | 요약 | 좁혀야 할 개발 문제 |
|---|---|---|---|
| 1 | 기립 보조 장치 (정치현) | 스프링 수평 슬라이더 위치로 작용점·보조 모멘트 조절, 메인 스프링 + 압축력 조절용 스프링 결합, 댐퍼 | 균형 능력이 낮은 사용자의 부상 위험, 체중별 필요 힘, 스프링·댐퍼의 비선형 거동 해석 |
| 2 | 소방 호스 이동 보조 (김강빈) | 호스 소재 변경, 뱀처럼 움직이는 구조, 소방차 동력 활용 능동 구동, 내부 압력 제어 검토 | 기계적 모션 제어 방식, 감아 보관할 때의 구조적 제약 (복잡한 구조·수압 제어만으로는 구현·창의성 한계) |
| 3 | VTOL 드론 날개 기구 (김태환·김홍범) | 접이식 날개 선행사례 기반 비행 효율 향상 / 날개 받음각 조절을 통한 착륙 자세 제어 | 비행 시연·전자 제어 비중 → 활공·회전·낙하 중 날개의 역할, 질량·날개 위치에 따른 구조적 작용을 기계적으로 구체화 |
| 4 | 하중 부담 경감 장구류 (김태환) | 군·경·소방관을 위한 배낭·조끼형 보조 장치 | 선행 연구가 많음 → 추가 질량을 상쇄하는 구조, 기존 장치보다 나은 하중 경감 효과를 구현으로 증명 |
| 5 | 외란 균형 유지를 위한 수동형 꼬리·다리 메커니즘 (김홍범) | 드론 횃대 착지용 다리에 꼬리를 결합해 외란(나뭇가지 진동·바람)에 의한 진동 제어, 균형 유지 에너지 저감 | 기구적으로 걸어다닐 때에도 도움이 되는 수동형 꼬리 구조 |
