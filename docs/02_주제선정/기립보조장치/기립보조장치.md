## 2. 현재 메커니즘 (9/30 기준)
### 2.1 구성 요소
| 요소 | 역할 |
|---|---|
| 계측 스프링 | 체중을 감지 |
| 피니언 | 미세 변위를 증폭해 보조 스프링의 위치를 자동으로 결정 |
| 받침대 | 위치가 정해지면 걸려 고정 |
| 보조 스프링 | 착석 시 압축되었다가 기립 시 팽창하며 보조력을 제공 |
| 속도 제한용 브레이크 | 보조력이 과해 좌면이 튀어 오르는 것을 막음 |
| 댐퍼 | 9/28: 착석(하강) 시에만 작동 / 9/30: 양방향 작동 여부가 남은 과제 |

### 2.2 동작 순서
1. 계측 스프링이 체중을 감지하고, 피니언이 미세 변위를 증폭해 보조 스프링의 위치를 결정한다.
2. 위치가 정해지면 받침대가 걸려 고정된다.
3. 착석 시 보조 스프링이 압축된다.
4. 기립 시 보조 스프링이 팽창하며 보조력을 제공한다. 속도 제한용 브레이크가 좌면이 튀어 오르는 것을 막는다.
5. 좌면이 수평에 도달하면 원위치로 복귀한다.

### 2.3 설계 조건
- 목표 체중 범위: 40–80 kg (최대 100 kg), 피니언 크기와 스프링 강성으로 조정 (9/30)
- 환자 대부분은 하지 근력의 약 35%만 보조받아도 기립이 가능하고, 하중은 기립 초기에 집중 → 보조 구간을 초반부로 한정 (9/28)
- 체중에 따른 좌면 기울기 차이는 계산상 약 1°로 무시 가능한 수준 (9/28)
