# 좌판 최대 올림각 검토 — 최소각과 최대각

> 작성: 김강빈 · 2026-10-06 · 상태: **개인 검토 (팀 논의 전)**
> 대상: 앞끝 힌지 틸트 좌판(현재 최대 20.3°)을 쓰는 휠체어 기립 보조 기구 전체
> 관련 파일: [`좌판각도_검토_계산.py`](좌판각도_검토_계산.py) (계산 코드), [`기립역학_분석.md`](기립역학_분석.md) (인체 모델의 출처)
> 수치는 준정적(힘의 평형) 계산값이고 측정값이 아니다. 인체는 신장 1.70 m · 체중 70 kg 한 가지만 계산했다.

## 요약
1. **20°로는 부족하다.** 좌판이 20° 올라간 자세에서 몸통을 30° 숙여도, 휠체어에서 흔한 발 위치(배측굴곡 15–20°)에서는 질량중심이 뒤꿈치 위에 겨우 오거나(+0.7 cm) 못 온다(−2.7 cm). 무릎 모멘트는 8–10 %만 줄어든다.
2. **최소각은 약 30–40°다.** 몸통 30° 이내로 질량중심을 뒤꿈치 위에 올리려면 17.5–29.2°, 발목 위까지 올리려면 32.5–42.1°가 필요하다(배측굴곡 20°–15°).
3. **최대각은 약 34–40°다(브레이크를 건 상태, 좌판 마찰 0.3–0.4, 120 kg).** 그 위로는 사용자가 좌판을 뒤로 미는 힘 때문에 앞바퀴가 들린다. 바닥에서 미끄러지는 것보다 뒤로 들리는 것이 먼저 온다.
4. **두 범위가 겹치는 곳은 좁다: 좌판 마찰 0.3이면 32.5–34.3°, 0.4이면 32.5–40.1°.** 그것도 브레이크를 걸고, 발을 배측굴곡 20° 이상 당겼을 때다. 브레이크가 풀려 있으면 17–22°를 넘는 순간 휠체어가 밀린다.
5. **무릎 모멘트를 35 % 줄이는 것은 틸트만으로는 44–55°가 필요해서 최대각을 넘는다.** 앞끝 힌지 틸트는 엉덩이를 올리는 동시에 앞으로 밀어서, 무릎이 앞으로 나가기 때문이다.

## 1. 계산 방법
### 1.1 최소각
- 인체 모델은 `기립역학_모델.py`와 같다(발·하퇴·대퇴·HAT 4분절, Winter의 분절 길이·질량비, 좌석 높이 47 cm, 고관절은 좌면 위 9 cm).
- 엉덩이는 좌판에 붙어서 앞 피벗을 중심으로 좌판과 같이 돈다고 보았다. 발은 바닥에 고정이고, 무릎 위치는 다리 길이로 정해진다.
- 고관절 위치는 앞 피벗에서 25 cm 뒤(v3의 좌골결절 위치)로 두었다. `기립역학_분석.md`의 13 cm(앞으로 당겨 앉음)도 비교했다.
- 좌판이 $\theta$만큼 올라간 자세에서 좌판 반력이 0이라고 놓고(엉덩이 이탈 순간), 다음을 구했다.
  - 질량중심(CoM)을 뒤꿈치 위 / 발목 위에 올리는 데 필요한 몸통 경사
  - 몸통을 30°로 숙였을 때의 CoM 위치와 무릎 신전 모멘트
- 몸통 경사 30°는 `기립역학_분석.md`에 인용한 최대 HAT 경사(좌석 40 cm에서 34.6°, 50 cm에서 28.6°, Yoshioka 2014) 사이의 값이다.
- 기준 두 가지:
  - **필수**: 몸통 30° 이내로 CoM이 뒤꿈치 위에 온다 (이보다 못하면 운동량 없이는 뒤로 넘어감)
  - **권장**: 몸통 30° 이내로 CoM이 발목 위에 온다 (운동량에 기대지 않고 좌판을 떠날 수 있음)

### 1.2 최대각
좌판이 올라간 채로 체중을 싣는 순간(앉기·계측)이 가장 불리하다. 좌판이 받는 수직 하중을 $V = 0.7\,mg$(v3 가정), 좌판과 옷 사이 마찰계수를 $\mu_s$라 하면, 사용자가 미끄러지지 않으려고 발로 버티는 최소 수평력은

$$
H = V\tan\!\left(\theta - \arctan\mu_s\right)\qquad(\theta > \arctan\mu_s)
$$

이고, 같은 크기의 힘이 좌판 높이 $h_s = 0.47 + b\sin\theta$에서 휠체어를 뒤로 민다. 브레이크를 건 뒷바퀴와 앞바퀴의 수직 반력은(휠체어 무게 $W_c$, 앞바퀴 접지점 기준 모멘트)

$$
R_r = \frac{V\,(z_f - z_s) + W_c\,(z_f - z_c) + H\,h_s}{z_f - z_r},\qquad R_f = V + W_c - R_r
$$

- 앞바퀴 들림: $R_f < 0$
- 바닥 미끄럼: $H > \mu_w R_r$ ($\mu_w$ = 뒷바퀴와 바닥의 마찰계수)
- 브레이크가 풀려 있으면 $H > 0$인 순간 밀린다. 한계는 $\theta = \arctan\mu_s$.

값: 뒷바퀴·앞바퀴 접지점 $z_r$ = −0.17, $z_f$ = 0.23 m(3D 모델, 앞바퀴는 임의값), 휠체어 20 kg(사양표), 무게중심 $z_c$ = 0(가정), 하중점 $b$ = 0.25 m. $\mu_s$와 $\mu_w$는 측정값이 없어 범위로 계산했다.

## 2. 최소각 결과
### 2.1 필요한 좌판 각 (고관절이 앞 피벗에서 25 cm 뒤)
| 발 위치 (초기 배측굴곡) | 필수: CoM 뒤꿈치 위, 몸통 ≤ 30° | 권장: CoM 발목 위, 몸통 ≤ 30° | 무릎 모멘트 −35 % (몸통 30°) | 배측굴곡이 30°를 넘는 각 |
|---|---|---|---|---|
| 25° (발을 많이 당김) | 1.3° | 21.4° | 43.9° | 34.4° |
| 20° | 17.5° | 32.5° | 49.1° | 49.2° |
| 15° | 29.2° | 42.1° | 54.6° | 59.6° |

- 휠체어는 발판과 앞바퀴 때문에 발을 뒤로 당기기 어렵다(`기립역학_분석.md` §6). 배측굴곡 15–20°가 현실적인 범위라고 보면 필수 17.5–29.2°, 권장 32.5–42.1°다.
- 무릎 모멘트 −35 %의 기준값은 좌판 수평·배측굴곡 25°에서 CoM을 뒤꿈치 위에 올린 자세의 2.07 N·m/kg(양다리)이다.

### 2.2 각도별 자세 (몸통 30° 고정, 고관절 25 cm 뒤)
| 좌판 각 | 고관절 높이 | CoM 위치 (뒤꿈치 기준, 배측굴곡 25° / 20° / 15°) | 무릎 모멘트 (같은 순서, 2.07 대비) |
|---|---|---|---|
| 0° | +0.0 cm | −0.2 / −3.6 / −7.1 cm | 101 / 102 / 103 % |
| 20° | +7.9 cm | +4.1 / +0.7 / −2.7 cm | 88 / 90 / 92 % |
| 30° | +11.1 cm | +7.0 / +3.6 / +0.3 cm | 79 / 82 / 85 % |
| 40° | +13.6 cm | +10.3 / +7.0 / +3.7 cm | 69 / 73 / 77 % |
| 50° | +15.4 cm | +14.0 / +10.8 / +7.4 cm | 59 / 64 / 69 % |

- 발 길이는 24.2 cm, 발목은 뒤꿈치에서 4.4 cm 앞이다.
- 고관절 높이는 각도를 키울수록 덜 올라간다(20°에서 +7.9 cm, 50°에서 +15.4 cm, 최대 +16.6 cm). 앞 피벗을 중심으로 도는 원호라서 각이 커지면 위보다 앞으로 간다.
- 그래서 무릎이 앞으로 밀려 배측굴곡이 늘고(20°에서 +2.3–3.1°, 40°에서 +6.3–8.1°), 무릎 모멘트가 기대만큼 줄지 않는다.

### 2.3 앞으로 당겨 앉은 경우 (고관절 13 cm 뒤, 배측굴곡 25°)
고관절이 피벗에 가까워 틸트 효과가 더 작다: 20°에서 고관절 +3.8 cm, 무릎 모멘트 94 %, 50°에서도 +6.2 cm, 82 %. 틸트 좌판은 **뒤쪽에 깊이 앉아야** 효과가 있다.

## 3. 최대각 결과
### 3.1 브레이크를 건 상태 (앞바퀴가 들리는 각 / 바닥에서 미끄러지는 각)
| 좌판 마찰 $\mu_s$ | 40 kg | 70 kg | 120 kg | 바닥 미끄럼 ($\mu_w$ = 0.3, 120 kg) |
|---|---|---|---|---|
| 0 (마찰 없음) | 23.8° | 19.2° | 16.5° | 22.9° |
| 0.2 | 35.6° | 31.0° | 28.3° | 33.9° |
| 0.3 | 41.5° | 37.0° | 34.3° | 38.9° |
| 0.4 | 47.3° | 42.8° | 40.1° | 43.5° |
| 0.5 | 52.8° | 48.4° | 45.7° | 47.7° |

- 표의 40·70·120 kg 열은 앞바퀴가 들리기 시작하는 각이다. 무거울수록 휠체어 자중(20 kg)의 몫이 줄어 먼저 들린다.
- 바닥 미끄럼은 $\mu_w$ = 0.3에서도 들림보다 2–6° 뒤에 온다. $\mu_w$ = 0.5 이상이면 62° 이상이라 문제가 되지 않는다. **지배 조건은 뒤로 들림**이다.
- 좌판이 미끄러우면(마찰 0) 지금의 20°에서도 70 kg 이상은 앞바퀴가 들린다.

### 3.2 브레이크가 풀린 상태
수평력이 조금이라도 생기면 휠체어가 뒤로 구른다. 한계는 $\arctan\mu_s$로, $\mu_s$ = 0.2 / 0.3 / 0.4에서 11.3° / 16.7° / 21.8°다. **20°를 넘기려면 브레이크가 걸려 있어야 한다.**

### 3.3 예: 35°에서의 힘 ($\mu_s$ = 0.3 / 0.4)
| 체중 | 뒤로 미는 힘 $H$ | 앞바퀴 반력 $R_f$ | 필요한 바닥 마찰 |
|---|---|---|---|
| 70 kg | 159 / 113 N | 26 / 97 N | 0.24 / 0.19 |
| 120 kg | 273 / 193 N | −15 (들림) / 107 N | 0.26 / 0.21 |

### 3.4 뒤로 들림 한계: 접지점 기준과 바퀴축 기준 (브레이크 걸림)
뒤로 넘기는 모멘트 $H\,(h_s - y_p)$가 버티는 모멘트 $V\,(z_s - z_r) + W_c\,(z_c - z_r)$를 넘으면 앞바퀴가 들린다. 회전 중심의 높이 $y_p$를 무엇으로 보느냐에 따라 한계가 달라진다.

| 좌판 마찰 $\mu_s$ | 접지점 기준 ($y_p$ = 0), 40 / 70 / 120 kg | 바퀴축 기준 ($y_p$ = 0.295 m), 40 / 70 / 120 kg |
|---|---|---|
| 0 | 23.8° / 19.2° / 16.5° | 40.8° / 35.1° / 31.5° |
| 0.2 | 35.6° / 31.0° / 28.3° | 52.7° / 47.2° / 43.5° |
| 0.3 | 41.5° / 37.0° / 34.3° | 58.8° / 53.4° / 49.8° |
| 0.4 | 47.3° / 42.8° / 40.1° | 64.8° / 59.5° / 56.1° |
| 0.5 | 52.8° / 48.4° / 45.7° | 70.7° / 65.5° / 62.1° |

- 바퀴축 기준이 접지점 기준보다 15–18° 크다. 뒤로 미는 힘의 팔 길이가 좌판 높이 전체(0.47 m + α)에서 바퀴축 위 부분(0.18 m + α)으로 줄기 때문이다. 예: 120 kg · $\mu_s$ 0.3 · 35°에서 넘기는 모멘트는 접지점 기준 167 N·m, 바퀴축 기준 87 N·m이고 버티는 모멘트는 161 N·m다.
- **어느 쪽이 맞는가**: 토글 브레이크는 타이어를 프레임에 눌러 바퀴와 프레임을 한 몸으로 묶는다. 그러면 휠체어는 바퀴째로 **접지점을 중심으로** 넘어가므로 접지점 기준이 실제 한계다(§3.1의 표와 같은 값).
- 바퀴축 기준은 휠체어를 붙잡는 수평력이 바퀴축 높이에 걸릴 때의 값이다. 뒷바퀴 뒤를 벽이나 턱이 바퀴축 높이에서 받치는 경우, 또는 바퀴는 프레임에 묶지 않고 축 자체를 바닥 쪽에 고정하는 장치를 쓰는 경우에 해당한다.
- 민감도(120 kg, $\mu_s$ 0.3): 휠체어 무게중심이 앞뒤로 5 cm 움직이면 한계가 접지점 기준 33.1–35.4°, 바퀴축 기준 48.2–51.3°로 변한다. 하중점이 앞 피벗에서 13 / 20 / 25 / 30 cm 뒤이면 접지점 기준 45.4 / 39.0 / 34.3 / 29.3°, 바퀴축 기준 66.5 / 57.0 / 49.8 / 41.9°다. **깊이 앉을수록(하중점이 뒷바퀴에 가까울수록) 먼저 들린다.**

## 4. 두 범위를 겹쳐 보면
| 조건 | 범위 |
|---|---|
| 최소각 — 필수 (배측굴곡 20°–15°) | 17.5–29.2° 이상 |
| 최소각 — 권장 (배측굴곡 20°–15°) | 32.5–42.1° 이상 |
| 최대각 — 브레이크 걸림, $\mu_s$ 0.3–0.4, 120 kg | 34.3–40.1° 이하 |
| 최대각 — 브레이크 풀림, $\mu_s$ 0.3–0.4 | 16.7–21.8° 이하 |

- 권장 기준과 최대각이 겹치는 곳은 배측굴곡 20°·브레이크 걸림·120 kg까지 기준으로 **$\mu_s$ = 0.3이면 32.5–34.3°, $\mu_s$ = 0.4이면 32.5–40.1°**다. 배측굴곡 15°에서는 권장 기준(42.1°)이 최대각을 넘어 겹치지 않는다.
- 35°를 택하면: 고관절 +12.4 cm, 몸통 30°에서 CoM이 뒤꿈치 앞 +5.3 cm(배측굴곡 20°), 무릎 모멘트 78 %.
- 현재의 20.3°는 필수 기준(17.5°, 배측굴곡 20°)을 겨우 넘는 수준이고, 브레이크 없이 쓸 수 있는 한계(16.7–21.8°)와 같은 자리다.

## 5. 설계에 주는 영향 (팀 논의 필요)
| 항목 | 내용 |
|---|---|
| 기구 재설계 | 최대각을 35°로 올리면 좌판을 드는 일이 $\sin 35° / \sin 20.3°$ = 1.65배가 된다. 보조 스프링 힘이나 행정, 지렛대 회전각, 호 홈 길이를 모두 다시 잡아야 한다 |
| 앉기·계측 자세 | 계측은 좌판이 다 올라간 자세에서 한다. 35° 경사면에 앉아야 하고($\tan 35°$ = 0.70 > $\mu_s$), 발로 113–273 N을 버텨야 한다. 계측 자세를 낮은 각에서 하는 방법을 검토 |
| 브레이크 연동 | 20°를 넘기면 브레이크가 필수다. 레버 없는 안에서는 브레이크가 걸려 있는지 보장할 방법이 없다 |
| 뒤로 들림 대책 | 전복 방지 보조 바퀴, 좌판 표면 마찰 확보, 하중점을 앞으로 옮기는 방법 |
| 좌판 운동 | 앞끝 힌지 틸트만으로는 무릎 모멘트 −35 %(44–55°)에 닿지 못한다. 좌판이 위로 올라가면서 기우는 방식(상승 + 틸트)이면 엉덩이를 앞으로 밀지 않고 올릴 수 있다. 10/2에 틸트를 고른 결정을 다시 볼 필요가 있다 |
| 발 위치 | 발판을 젖히고 발을 당길수록 필요한 각이 줄어든다(배측굴곡 5°마다 약 10–16°). 발판 구조가 결과를 크게 바꾼다 |

## 6. 한계
- 준정적 계산이다. 실제 기립은 몸통을 숙이는 운동량을 쓰므로(`기립역학_분석.md` 요약 2) 필수 기준보다 작은 각에서도 일어설 수 있다. 근력이 약한 사용자를 대상으로 한다는 점에서 준정적 기준을 썼다.
- 엉덩이가 좌판에서 미끄러지지 않고 같이 돈다고 보았다. 실제로는 각이 커지면 앞으로 미끄러져 내려온다.
- 인체는 한 가지 체격만 계산했다. 무릎 모멘트는 자세를 유지하는 값이고, 근육이 낼 수 있는 한계는 넣지 않았다.
