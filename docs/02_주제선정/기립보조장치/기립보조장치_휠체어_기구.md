## 요약
1. **목표**: 체중이나 앉는 위치가 달라 링크 하중 $R$이 달라져도 보조력 ÷ $R$(보조율)이 같은 기구. 설계 보조율 35 % (9/28 회의록: 하지 근력의 약 35 %).
2. **방식**: v3의 구성(계측 스프링 → 랙·피니언·드럼 → 케이블 → 수레 → 보조 스프링 → 지렛대 → 들어올림 링크 → 좌판)을 그대로 쓰고, 휠체어(WYK874-41) 좌석 아래에 넣었다. 좌판은 **앞끝 힌지**를 축으로 뒤쪽이 들린다.
3. **결과**: 체중 40–120 kg에서 보조율은 수레가 잠기는 순간 34.3–35.6 %, 좌판이 수평인 자세(일어서기 시작)에서 40.2–41.6 %다. 편차는 톱니판 피치(2.5 mm)에서 나온다.
4. **v3 상수를 그대로 쓸 수 없는 이유**: 휠체어 좌석 아래 높이에서 보조 스프링의 늘인 길이는 183 mm인데, v3 상수(F = 200 N, i = 8)로는 100 kg에서 행정이 111 mm라 가스 스프링이 들어가지 않는다. F = 450 N, i = 4로 바꿔 행정을 59 mm(120 kg) 이하로 줄였다.
5. **남은 문제**(§7): 모듈을 단 채로는 휠체어를 접을 수 없음, 바닥 간격 60 mm, 주행 중 좌판이 뜨는 조건, 받침 해제 힘, 댐퍼·브레이크 재검증.

## 1. 목표와 용어
- 좌판에 앉은 사용자가 들어올림 링크 위치에 주는 하중을 **링크 하중** $R$이라 한다. 좌판이 체중의 70 %를 받고(v3 가정), 하중점이 앞 피벗에서 $b$만큼 뒤에 있으면

$$
R = \frac{0.7\,m\,g\,b}{L}
$$

- $L$ = 앞 피벗–링크 거리(380 mm), $b$ = 앞 피벗–하중점 거리(v3: 좌골결절 250 mm).
- **보조율** = 링크 위치로 환산한 보조력 $A$ ÷ $R$. 이 값이 $m$과 $b$에 따라 변하지 않게 하는 것이 목표다.
- 부품 이름은 v3 화면의 이름을 그대로 쓴다. `기립보조장치.md`의 받침대 = 받침, 속도 제한용 브레이크 = 원심 브레이크, 보조 스프링의 위치를 정하는 부품 = 수레.

## 3. 보조율이 일정해지는 조건
계측 중(받침이 끼워진 상태) 지렛대 끝은 받침과 함께 $\delta$만큼 내려가고, 수레는 $s = s_0 + i\,\delta$로 끌려 나온다. 마찰을 빼면

$$
A = \frac{F\,s}{a},\qquad T = F_r + \frac{F\,\delta}{a},\qquad N = R - A = k\,\delta + i\,T
$$

($T$ = 케이블 장력, $F_r$ = 복귀 스프링 힘). $g = iF/(ak)$로 두고 정리하면

$$
R = k\,\delta\,(1+2g) + \frac{F\,s_0}{a} + i\,F_r,\qquad A = g\,k\,\delta + \frac{F\,s_0}{a}
$$

$s_0$를 아래 값으로 잡으면 상수항이 같은 비율이 되어, $\delta$(즉 $R$)와 무관하게

$$
s_0 = \frac{a\,g\,i\,F_r}{F\,(1+g)}\quad\Longrightarrow\quad \frac{A}{R} = \frac{g}{1+2g}
$$

- v3 상수로 검산: $s_0 = 350\times1.172\times8\times3/(200\times2.172) = 22.7$ mm (화면 23 mm), 평형 수레 위치 277.2 mm (화면 277 mm).
- $R$에는 체중 $m$과 하중점 거리 $b$가 곱으로 들어가므로, **체중이 달라도, 앉는 위치가 달라도** 보조율은 같다.
- 좌판이 사용자를 밀어 올리는 힘은 하중점에서 $A\,L/b = 0.35\times0.7\,mg = 0.245\,mg$로, $b$와 무관하게 체중의 24.5 %다(수레가 잠기는 순간 기준).

### 3.1 좌판이 내려간 뒤의 보조력
수레가 잠긴 뒤 좌판이 내려가면 지렛대가 $\varphi$만큼 기울고, 보조 스프링(수직, 힘 $F$ 일정)이 닿는 점의 높이는 $y_c = y_O - s\tan\varphi$다. 좌판 각을 $\theta$라 하면 가상일로

$$
A(\varphi) = \frac{F\,s}{L\cos\theta\,\cos^{2}\varphi}\left|\frac{\mathrm{d}\varphi}{\mathrm{d}\theta}\right|
$$

$\mathrm{d}\varphi/\mathrm{d}\theta$는 링크 길이 구속에서 수치로 구했다. 좌판 수평($\theta = 0$, $\varphi = 21.8^{\circ}$)에서 $A$는 계측 위치의 1.17배다. 이 배율은 각도에만 달려 있으므로 체중에 따른 비율은 그대로 유지된다.

## 5. 휠체어에 맞춰 바꾼 상수
보조 스프링은 레일 위 수레와 지렛대 사이에 선다. 지렛대가 수평일 때 길이(늘인 길이)는 $0.31 - 0.0125 - 0.115 = 0.1825$ m = 183 mm이고, 좌판이 수평이 되면 $s\tan 21.8^{\circ}$만큼 줄어든다(행정). 가스 스프링은 로드가 실린더 안으로 들어가야 하므로 조건을 **늘인 길이 ≥ 2 × 행정 + 50 mm**로 두었다(50 mm는 끝 이음 여유로 잡은 임의값).

| | v3 상수 그대로 (F = 200 N, i = 8) | 바꾼 값 (F = 450 N, i = 4) |
|---|---|---|
| 수레 위치 $s$ (100 kg / 120 kg) | 277 / 333 mm | 123 / 148 mm |
| 행정 (100 kg / 120 kg) | 111 / 133 mm | 49 / 59 mm |
| 2 × 행정 + 50 (120 kg) | 316 mm > 183 mm (불만족) | 168 mm ≤ 183 mm (만족) |
| 계측 스프링 강성 $k = iF/(ag)$ | 3.9 N/mm | 4.41 N/mm |
| 수레 초기 위치 $s_0$ | 23 mm | 5.0 mm |
| 드럼 반지름 (피니언 6 mm) | 48 mm | 24 mm |
| 톱니판 피치 | 5 mm | 2.5 mm (수레 이동 범위가 줄어 피치도 줄임, 임의값) |
| 걸쇠가 받는 힘 $F\tan\varphi + F_r$ (좌판 수평) | 83 N (v3 화면) | 183 N |

보조에 쓰는 일($F \times$ 행정)은 같으므로, 행정을 줄이면 그만큼 $F$가 커지고 걸쇠가 받는 힘도 커진다.

## 8. 한계
- 준정적 계산이다. 마찰(수레 마찰, 관절), 좌판 자중, 부품 질량은 넣지 않았다.
- 계측 중 식은 v3와 같은 선형 근사(지렛대 기울기 $\delta/a$)다. §6의 보조력은 링크 기구를 수치로 풀어 구했으므로, 톱니판 피치를 빼고 보면 선형식의 35.0 %보다 약 0.5 %p 높게(35.5 %) 나온다.
- v3의 식은 화면 값으로 확인한 것이다. v3 내부 계산과 다른 부분이 있을 수 있다(§2.2 마지막 줄의 1.2 % 차이).
- 기구 부품의 크기와 위치는 3D 모델에 넣기 위한 임의값이며 강도 계산을 하지 않았다.
