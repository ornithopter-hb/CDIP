## 진행 현황 (2026-09-23 기준)
- 단계: **주제 선정 전 후보 주제 검토**
- 주제는 아직 **최종 확정하지 않음**
- 다음 할 일: 후보를 목록으로 정리해 교수님께 전달 → 기계적 구동 방식·시연 가능성·안전성·기존 기술 대비 개선점을 중심으로 개발 문제를 좁혀 감

## 주제 선정 기준 (9/23 회의)
- **손으로 구동해 움직임이 보이는 기계적 구조**를 중심으로 시연 가능한 주제
- 지양: 스위치 작동만으로 끝나는 구성, 지나치게 익숙한 주제, 제작·시연이 불편한 구성
- 물을 사용하는 시연은 가급적 피함
